### What I work on

- **Agents with guardrails**: identity-bound tools, row-level security, human-confirmed writes, audit trails.
- **LLM pipelines in production shape**: queues, structured outputs, evaluation gates, human-in-the-loop validation.
- **Retrieval and speech**: hybrid semantic search, transcription, speaker diarization.
- **Agent tooling**: skills, plugins and harnesses for coding agents (Claude, Copilot, Oh My Pi, OpenCode).

---

### Featured

**[Atrium · people-agents](https://github.com/luccapinto/people-agents)**: governed AI agents for employee services. One conversational front door for HR where every tool is bound to the caller's identity, Postgres row-level security isolates each person's data, writes wait for a human click and every event lands in a hash-chained audit log. 14 agents, an Agent Studio with an evaluation gate and human approval, and a [live demo](https://luccapinto.github.io/people-agents/) that runs entirely in the browser.

**[scorecard-pipeline](https://github.com/luccapinto/scorecard-pipeline)**: event-driven pipeline that scores recruiting interviews. FastAPI, Redis Queue and PostgreSQL, pluggable transcription (WhisperX or OpenAI), Pyannote diarization, structured LLM scoring via OpenRouter and human validation of the evidence behind every score.

**[resume_ranker](https://github.com/luccapinto/resume_ranker)**: candidate-job matching with hybrid semantic search, bias governance and end-to-end explainability.

**[dash-conversacional](https://github.com/luccapinto/dash-conversacional)**: people analytics where AI decides the presentation and code decides the numbers.
